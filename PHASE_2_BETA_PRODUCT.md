# Phase 2: Beta Product

Goal: turn the audit into a repeatable customer workflow.

## Build

- Full SRO Analysis Engine:
  - AI grounding.
  - cross-platform AI citations.
  - SERP rank.
  - target page scrape.
  - competitor page scrape.
  - content gaps.
  - LLM synthesis.
- Persona Fan-Out Prompt Discovery.
- Niche Explorer.
- Prompt track/reject workflow.
- Citation outreach briefs.
- Bulk SRO for agencies.
- Monitoring alerts.

## Success Criteria

- Beta users run repeated scans and complete recommended tasks.
- Agencies can run multiple client audits in a batch.
- The product starts producing “what changed” evidence week over week.
